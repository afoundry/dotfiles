# Dotfiles

Version-controlled shell and editor config.

## What we added

This repo was created from resources listed below. Our contributions:

- **zshrc** — Zap plugin setup, Powerlevel10k theme, fzf key bindings (Ctrl+R history search, Ctrl+T file finder), fzf-tab completion, and sourcing logic for multiple fzf install paths (git, Debian, Arch)
- **install.sh** — Symlinks `zshrc` and `p10k.zsh` into `$HOME`, optional fzf install via apt
- **p10k.zsh** — Powerlevel10k config generated by `p10k configure`; versioned here and symlinked as `~/.p10k.zsh` so the wizard updates the repo file
- **README** — Setup instructions, wizard reference, font notes, license attribution

## How to view this README

- **Terminal:** `cat ~/.dotfiles/README.md` or `less ~/.dotfiles/README.md`
- **Cursor/VS Code:** File → Open File… → `~/.dotfiles/README.md`, or open the folder `~/.dotfiles` and click README.md

## Contents

- **zshrc** — Zsh config (Zap, Powerlevel10k, fzf, history search)
- **p10k.zsh** — Powerlevel10k prompt config (from `p10k configure`); symlinked as `~/.p10k.zsh`

## Setup

1. Symlink into `$HOME` (already done if you ran `install.sh`):
   ```bash
   ln -sf ~/.dotfiles/zshrc ~/.zshrc
   ```
2. Install fzf (for Ctrl+R history search and tab completion):
   - Debian/Ubuntu: `sudo apt install fzf`
   - Or from source: <https://github.com/junegunn/fzf#installation>
3. Restart Zsh: `exec zsh`
4. Run the Powerlevel10k wizard (see below).

## Powerlevel10k setup wizard

The wizard customizes prompt style, icons, and layout. You can run it anytime:

```bash
p10k configure
```

- **First time:** It often starts automatically after you open a new Zsh session. If not, run the command above.
- **Later:** Run `p10k configure` again to change style, colors, or segments.
- **Font:** For the full set of styles and icons, install [MesloLGS Nerd Font](https://github.com/romkatv/powerlevel10k#fonts) and set your terminal font to “MesloLGS NF” before running the wizard.

## Font (Powerlevel10k)

For full Powerlevel10k styles and icons, install **MesloLGS Nerd Font**:

- <https://github.com/romkatv/powerlevel10k#fonts>
- Then set your terminal font to "MesloLGS NF".

# Dotfiles local installation procedure

Version-controlled shell and editor configuration bundle featuring Zap, Powerlevel10k, and fzf.

## Prerequisites

Before running the installation setup, ensure your Linux server has the base dependencies installed:

```bash
sudo apt update && sudo apt install -y curl fzf git zsh
```

## Setup Instructions

Follow these exact steps to activate the environment profile cleanly:

### 1. Position the Repository Correctly
The custom setup script strictly expects the repository folder name to be hidden (`.dotfiles`) and positioned directly inside your `$HOME` directory. 

If you cloned the directory as standard `dotfiles` (without the prefix period), rename it immediately before executing scripts:
```bash
mv ~/dotfiles ~/.dotfiles
```

### 2. Provision the Missing Zap Core Binary
This repository tracks customized configuration profiles but does not package the underlying compiler engine binaries. Generate the target data directory layout and download the core `zap.zsh` engine module directly:
```bash
mkdir -p ~/.local/share/zap
zsh <(curl -s https://raw.githubusercontent.com/zap-zsh/zap/master/install.zsh) --branch release-v1
```

### 3. Link Configuration Framework Files
Navigate into your hidden profile folder context and execute the local install manager script to distribute symlinks across your home tree:
```bash
cd ~/.dotfiles
zsh install.sh
```
*Note: If prompted to overwrite existing target paths, select **Yes** to let the repository files take total control.*

### 4. Initialize and Complete Theme Compilation
Force your active terminal to re-read your shell configuration values. Zap will automatically discover your defined runtime extensions and pull them down into active memory:
```bash
exec zsh
```

## Powerlevel10k Setup Wizard
The style customizer tool usually launches automatically on first boot. If you need to reconfigure icons, layout structure, or prompt behaviors down the line, run:
```bash
p10k configure
```
